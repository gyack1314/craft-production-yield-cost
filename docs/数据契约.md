# 原始资料契约

所有资料均为本地合成。JSONL一行一条来源观察，row_id仅标识该观察；同业务ID可以在不同revision、批次或接收位置出现。未写revision的静态目录按文件给定值解释，不隐含线上查询。事实字段中的None为缺少来源值，不是零或否。

金额字段以minor结尾时为该币种最小单位整数；数量、位置、时间的单位以字段后缀和政策说明为准。日期为ISO日期；绝对时刻携带偏移；原始received字段决定可见性，不能仅按发生日期提前使用资料。后续业务修改以相同格式输入，不限定样本编号。

## 业务政策

### flow

piece为实物件数，kg为材料质量，不相加；其他单位需来源显式换算。各lot投入=对外/对内输出+报废+损耗+在制，返工/回用均为移动不是新增合格件，记录不闭合则显示缺口。

### allocation

费用池按成员非负basis_value占比分配，总权重零时待分配；联产品按参考价值乘实际可售数量分配；回用料抵扣不得超过外部购入同料参考价及该源批次可抵扣成本。配置缺失不自行估价。

### cycle

无外部投入/确定价值边界且无最终产出的纯循环没有确定单位成本，报告不可解释，不输出任意0。允许联合解或其他正确处理，不规定算法。

### close

以闭合且资料齐备批次纳入已结成本；尚未明确的费用在未分配池，未完成实物在制结转。原期间报告固定，补正只在posting_period记关联调整。比较需要同工艺和等级，跨工艺时需分别列产出结构/材料和价格敏感性，不能把差别全归价格。

## 资料检查

`python -m unittest discover -s tests -v`只检查资料字节与格式，不是尚未开发业务功能的验收。manifest.json中的摘要对应提交内原始字节，收到后续批次应独立登记来历，不修改旧原始记录。
